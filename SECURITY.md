# Security

Report a vulnerability in gatekit by email to james@unkey.com. Do not open a public issue for a security report.

Include the package, the version, and a description of the impact. You will get a reply acknowledging the report.

gatekit does not store Unkey root keys. Do not send a root key, a customer API key, or any other secret in the report. Describe the request shape without the credential.
